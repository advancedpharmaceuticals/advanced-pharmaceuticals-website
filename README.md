## Important before launch
1. Check the logo rendering. The supplied logo file is used as provided; a higher-resolution transparent PNG/SVG would make it sharper.
2. Review all company copy and replace any wording that needs to match official company/regulatory documentation.
3. Add verified product names, strengths, registrations and dosage forms before publishing a product-level catalogue.
4. The enquiry form opens the visitor's email application; it does not store or transmit form submissions itself.
